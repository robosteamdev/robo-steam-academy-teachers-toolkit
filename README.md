# ROBO STEAM ACADEMY — Teachers' Toolkit

![Co-funded by the European Union · ROBO STEAM ACADEMY · partner logos](images/logos_strip.png)

**Teachers' ST(R)EM: Robots in STEM Toolkit** — everything a teacher needs to teach robotics and programming with
**PicoBot**, a small mecanum-wheel robot with an arm, built on the **Raspberry Pi Pico 2 W / Pico W** and programmed in
**MicroPython**. Lesson plans for 32 double sessions (full course) or 10 sessions (short course), student materials, slide
decks, quizzes, reference documents, methodological guides and all lesson programs.

The toolkit is a result of the Erasmus+ project **ROBO STEAM ACADEMY** (KA220-VET-7CF4F308). It is free to use, share and
adapt (licence below).

## What is in each language folder

| Folder | Contents |
|---|---|
| `teachers/0_start_here/` | A0 Teacher's Guide — course plans, classroom organisation, safety |
| `teachers/1_modules/` | teacher editions of the modules M01–M12, quizzes with answers |
| `teachers/2_slides/` | one PowerPoint deck per module, with speaker notes |
| `teachers/3_reference/` | A1 hardware · A2 assembly and maintenance · A3 software set-up · A4 experiment set-ups · A5 troubleshooting · A6 glossary |
| `teachers/4_methodological_guides/` | G1 exploration-based teaching · G2 sensor calibration · G3 gamification · G4 assessment · G5 inclusion |
| `teachers/5_complete_course/` | all lessons in one book: full course and short course |
| `students/` | student editions of the modules, handouts, quizzes, S2 workbook, S3 reference cards, S4 challenge cards, textbook |
| `code/` | all lesson programs, one folder per module |
| `about/` | release note (contents and known gaps of the version) and public abstract |
| `sources/` | the source files (Markdown), pictures and build tools — for adapting or translating the toolkit |

Every document is available as **PDF** (to read and print) and **Word** (to adapt).

**Start here:** read the Teacher's Guide (`teachers/0_start_here/`), build and set up the robots with A2 and A3
(`teachers/3_reference/`), then teach with the teacher edition of each module and its slide deck.

## Robot programs

The PicoBot library and the ready robot programs are in the repositories of the project's GitHub account
**https://github.com/robosteamdev** (for example picobot-setup, picobot-web-control, picobot-line_following,
picobot-obstacle-avoidance, picobot-mission-control). The Teacher's Guide (section 17) explains which lesson uses which
repository. The lesson programs themselves are in the `code/` folder of each language pack.
